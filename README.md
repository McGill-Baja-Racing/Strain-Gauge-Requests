# McGill Baja Racing — Strain Gauge Requests

Coordinate Fall 2026 strain gauge requests, Electronics review, installation, and calibration or validation in this standalone repository.

Mechanical subsystem leads should [create a request](https://github.com/McGill-Baja-Racing/Strain-Gauge-Requests/issues/new?template=strain-gauge-request.md) using **Issues → New issue → Strain gauge request**. Read the [request guide](docs/REQUEST_GUIDE.md); estimates and TBD answers are welcome at submission.

Use **one issue per measurement setup**: a shared objective, component configuration, and calibration approach. Two identical tie rods may share an issue; unrelated suspension and drivetrain measurements need separate issues. Include the component quantity. Electronics selects gauge quantities, bridge configurations, and DAQ equipment.

1. Submit the objective, expected loads, preliminary calibration/validation concept, and dates.
2. Electronics performs initial technical review for feasibility, equipment estimates, effort, and priority; missing details return to the lead.
3. Before installation approval, confirm final locations, selected equipment, component delivery, a feasible calibration/validation plan, available fixtures and references, an owner, and sufficient scheduled time.
4. Install, allow curing, wire, and verify electrical operation; then perform and document calibration or validation.
5. Mark **Ready for Testing** only when usable data can be collected. Approval of a calibration plan is not completion of calibration.
